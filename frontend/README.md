# Frontend — Professional Network

Next.js (Pages Router) + Redux Toolkit client for the Professional Network app.

See the [main README](../README.md) for features, architecture, setup and deployment.

```bash
cp .env.example .env.local   # set NEXT_PUBLIC_API_URL
npm install
npm run dev                  # http://localhost:3000
npm run lint
npm run build && npm start   # production build
```
